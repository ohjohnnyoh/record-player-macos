# Record 1.7

## Что нового

- Автоматическая проверка обновлений раз в сутки.
- Установка новой версии прямо внутри Record.
- Действия «Обновить», «Напомнить завтра» и «Пропустить эту версию».
- Стеклянная панель с прогрессом загрузки и установки.
- Ручная проверка и параметры обновлений в настройках.

## What is new

- Automatic update checks once a day.
- New versions can be installed directly from Record.
- Update, Remind Me Tomorrow, and Skip This Version actions.
- A glass panel with download and installation progress.
- Manual checks and update preferences in Settings.
