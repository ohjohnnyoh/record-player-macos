# Record screenshot gallery

Финальный набор скриншотов интерфейса для README, релизных заметок и страницы проекта.

## Основные экраны

### Все станции

Главный каталог с жанрами, карточками станций и стеклянным плеером.

![Все станции](01-all-stations.png)

### Избранное

Сохранённые станции в компактной сетке.

![Избранное](02-favorites.png)

### История

История прослушивания с треками, станциями и временем воспроизведения.

![История](03-history.png)

### Статистика прослушивания

Локальная статистика по станциям и времени прослушивания.

![Статистика прослушивания](04-listening-stats.png)

### Поиск

Фильтрация каталога по названию станции и жанру.

![Поиск](05-search.png)

### Полный режим станции

Расширенный экран с крупной обложкой текущего трека, управлением и историей эфира.

![Полный режим станции](06-full-station.png)

### Полный режим с боковой панелью

Адаптивная компоновка того же экрана при открытой навигации по жанрам.

![Полный режим с боковой панелью](12-full-station-sidebar.png)

## Плеер и системные элементы

### Настройки воспроизведения

Качество потока, таймер сна, история треков и быстрые действия.

![Настройки воспроизведения](07-player-options.png)

### Мини-плеер

Отдельное компактное окно с обложкой, управлением и регулировкой громкости.

![Мини-плеер](08-mini-player.png)

### Плеер в строке меню

Быстрый доступ к текущему треку и избранным станциям без открытия основного окна.

![Плеер в строке меню](09-menubar-player.png)

### Цветовые акценты

Системная и пользовательские акцентные палитры интерфейса.

![Цветовые акценты](10-accent-palettes.png)

### English interface

Главный экран с автоматически выбранной английской локализацией macOS.

![English interface](11-all-stations-english.png)
